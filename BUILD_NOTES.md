# Build notes — Ghostpanter/scrcpy-android

## Rebuild (assembleDebug)

```bash
git clone https://github.com/Ghostpanter/scrcpy-android.git
cd scrcpy-android
# Optional (only for scripts/build-server / check-server-source):
git submodule update --init --recursive

# Fetch pinned scrcpy-server.jar into app assets (gitignored binary):
./scripts/update-server

# If gradle/wrapper/gradle-wrapper.jar is missing, restore once:
#   gradle wrapper --gradle-version 8.13

./gradlew :app:assembleDebug
```

## Requirements
- JDK 17
- Android SDK (compileSdk/targetSdk 37, build-tools per `app/build.gradle`)

## Intentionally omitted
| Path | Why |
|------|-----|
| `app/src/main/assets/scrcpy-server.jar` | Regenerated by `scripts/update-server` |
| `local.properties`, `.gradle/`, `build/`, `app/build/`, `artifacts/`, `*.apk` | Local / caches / outputs |
| `vendor/scrcpy/**` | Submodule (Genymobile/scrcpy); not needed after `update-server` |
| Fastlane PNG screenshots / icon | Store listing; not required to build |
| `gradle/wrapper/gradle-wrapper.jar` | Binary (~44KiB); restore via `gradle wrapper` |

## Vendored for Gradle
- `vendor/libadb-android/` — `:adb` project sources

`com.ghostpanter.scrcpy` (`0.5-ghostpanter`)
